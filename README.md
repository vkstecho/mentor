# Mentor 3.0 Frontend (production)

1. Copy `firebase.config.example.js` → `firebase.config.js` and fill with **live** Firebase web config.
2. Upload **all contents** of this folder to your site root / GitHub Pages (`index.html` at `/`).
3. Backend must already be deployed (see `../PRODUCTION_DEPLOY.md`).

Secure flags in `js/mg-config.js` are **enabled** (`SECURE_DATA_ENABLED` / `SECURE_BOOKINGS_ENABLED` = true).
