KPI Dashboard — Plant Metrics

Practical KPIs for metalliser / converting plants. Use these on shift boards and daily meetings — not theory slides.

Core production KPIs

OEE (simple)Availability × Performance × Quality
Yield %Good output ÷ Raw input × 100
OD hit rateRolls within OD target ÷ Total rolls
Downtime minBreakdown + changeover + wait

Formulas you can put on a whiteboard

Availability % = Run time / Planned time × 100
Performance %  = (Ideal cycle × Count) / Run time × 100
Quality %      = Good count / Total count × 100
OEE %          = A × P × Q

Yield %        = Good kg / Input kg × 100
Scrap cost/day ≈ Scrap kg × Material ₹/kg
Cost / sqm     = (Total cost for period) / (Good sqm)

Shift board checklist

  • Plan vs actual meters / kg
  • Top 3 downtime reasons (with minutes)
  • OD / adhesion / visual reject count
  • Wire / boat / power note for metalliser shifts
  • Action owner + due time (not “will improve”)

Common mistakes

  • Tracking only output meters — ignore quality and stops
  • No standard definition of “planned time” across shifts
  • Mixing good kg and total kg in yield
  • KPIs without a named owner
